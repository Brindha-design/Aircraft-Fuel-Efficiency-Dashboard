# ✈️ Aircraft Fuel Efficiency Dashboard

## 📌 Project Overview

This project is an interactive Power BI dashboard created to analyze aircraft fuel consumption, distance travelled, and fuel efficiency.

The dashboard helps compare aircraft performance and identify patterns in fuel usage.

## 🎯 Project Objective

The main objective of this project is to:

- Analyze aircraft fuel consumption
- Compare fuel usage between aircraft types
- Analyze distance travelled
- Identify fuel-efficiency patterns
- Present the analysis using an interactive Power BI dashboard

## 🛠️ Tools Used

- Microsoft Excel – Data preparation
- Power BI – Data visualization and dashboard creation
- DAX – Calculations and measures

## 📊 Dashboard Features

- Fuel Consumption Analysis
- Distance Travelled Analysis
- Aircraft-wise Comparison
- KPI Cards
- Interactive Filters and Slicers
- A320 vs B737 comparison

## 📈 Key KPIs

The dashboard includes important performance indicators such as:

- Total Fuel Consumption
- Distance Travelled
- Average Fuel Consumption
- Aircraft Count
- Fuel Efficiency

## 🔍 Analysis Performed

The project analyzes:

1. Fuel consumption across aircraft types
2. Distance travelled by aircraft
3. Differences in fuel usage between A320 and B737
4. Overall aircraft fuel-efficiency patterns

## 💼 Business Value

This dashboard can help aviation and airline operations teams monitor aircraft fuel usage, compare aircraft performance, and identify areas that may require further investigation.
